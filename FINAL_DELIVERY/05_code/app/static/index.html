    How it works
    • The message is cleaned exactly like the training data: Unicode normalisation (Sinhala and Tamil joiners kept), operator warning removed, links / phone numbers / amounts masked.
    • LinearSVC (three-class) — word + character TF-IDF, the best classical model (default answer).
    • XLM-R (three-class) — fine-tuned multilingual transformer, the best deep model (second opinion, needs PyTorch).
    • Model choice: three-class formulation (fewer false alarms on real SMS), then ranked by held-out test macro-F1.
    • On the real benchmark the two models are statistically tied (McNemar p = 0.71): both catch about 90% of real scams and wrongly flag about 18–20% of real normal / promotional SMS.
    Known weaknesses
    • Real Sri Lankan service messages (OTPs, telco notices) and romanised Singlish / Tanglish chat are sometimes flagged as scams.
    • Very small real Tamil sample; per-language results for Tamil are not reliable.
